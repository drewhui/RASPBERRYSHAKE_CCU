調查過程 Investigation

即時震度演算法原本假設「持續一段時間的 PGV/PGA 門檻穿越即代表真實地動， 不需要額外的波形判別器」。實際比對後發現三個獨立資料來源在同一時刻互相矛盾： 事件封存的原始波形、dashboard 自己的週期性採樣、以及 pick_ew （獨立的 C 模組）對同一測站的獨立量測，三者都顯示現場平靜，只有即時演算法 自己算出異常高值。目前判斷問題出在演算法內部的計算邏輯，而非感測器雜訊或 外部干擾，但確切成因尚未定位——已在程式碼中加入診斷 log，等下次異常重現時 直接記錄當下的原始樣本以供分析。

The real-time intensity path assumed a sustained PGV/PGA threshold crossing was inherently real shaking. Cross-checking against three independent sources at the same instant — the archived raw waveform, the dashboard's own periodic sample, and pick_ew's (a separate C module) independent measurement — all showed a calm station, contradicting the real-time algorithm's own reading. This points to a bug in the algorithm's internal bookkeeping rather than sensor noise or external interference, though the exact cause is still open; diagnostic logging was added to capture raw samples the next time it recurs.
